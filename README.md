# InformaticaNube

## Descripción

Este repositorio contiene la implementación de algoritmos de ordenación de orden n² (como bubble sort y selection sort) en **C** y **Java**. Estos algoritmos se utilizarán para ordenar datos de consumo eléctrico capturados mediante un medidor proporcionado por la profesora.

## Objetivo

El proyecto forma parte de la asignatura **Informática en la Nube** impartida en la **Universitat de les Illes Balears (UIB)**. Su objetivo es:

- Implementar algoritmos de ordenación n² en C y Java
- Capturar datos de gasto eléctrico utilizando un medidor
- Ordenar y procesar estos datos para su análisis

## Tecnologías

- **Lenguajes**: C, Java
- **Algoritmos**: Ordenación O(n²)
- **Hardware**: Medidor eléctrico
